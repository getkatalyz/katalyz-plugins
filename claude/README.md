# Katalyz for Claude

Work with the dealrooms you can access as a Katalyz seller. The plugin connects Claude to the production Katalyz MCP server and adds focused workflows for finding and briefing dealrooms, creating rooms or unpublished templates from an AI brief, reviewing seller tasks and meetings, and collaborating in room discussions. AI creation can use existing Katalyz resources or original files Claude can access and upload as private temporary resources.

For private testing, load the plugin folder or ZIP in Claude. After the directory listing is published, install Katalyz from Claude's plugin directory. Connect Katalyz from the plugin's Connectors tab. Sign in with your Katalyz work account and review the requested permissions. Claude can only use tools allowed by your Katalyz organization, seller account, and granted OAuth scopes. Template creation, AI template creation, and file upload have separate optional permissions; meeting transcripts require their separate permission. To transfer original files from another app, Claude needs code execution, access to their bytes, and network access to the short-lived signed upload URL. The create-dealroom skill includes a standard-library uploader for that transfer. If any of those capabilities are unavailable, upload files in Katalyz and ask Claude to find them by name. AI room and template creation runs in Katalyz's background worker; Claude checks the result in chat for up to two minutes, or delegates status checks in Cowork or Claude Code when background subagents are available. A failed AI template can be retried in the same draft after Claude reports the reason and you confirm the inputs.

Creating a room, posting a comment, or sending an invitation changes live Katalyz data. Buyer invitations queue email and reminders immediately after you confirm the room, recipient, and role. For help, visit [Katalyz support](https://katalyz.crisp.help/).
