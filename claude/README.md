# Katalyz for Claude

Work with the dealrooms you can access as a Katalyz seller. The plugin connects Claude to the production Katalyz MCP server and adds focused workflows for finding and briefing dealrooms, creating rooms or unpublished templates, editing their pages, widgets, tasks, and design, reviewing seller tasks and meetings, and collaborating in room discussions. AI creation can use existing Katalyz resources or original files Claude can access and upload as private temporary resources. Files used in page widgets must be durable library resources.

For private testing, load the plugin folder or ZIP in Claude. After the directory listing is published, install Katalyz from Claude's plugin directory. Connect Katalyz from the plugin's Connectors tab. Sign in with your Katalyz work account and review the requested permissions. Claude can only use tools allowed by your Katalyz organization, seller account, and granted OAuth scopes. Reading templates, editing room or template content, managing resources, and uploading files to the shared library have separate optional permissions; meeting transcripts require their separate permission. Existing connections must reauthorize to gain new scopes. To transfer an original file up to 30 MB from another app, Claude needs code execution, access to the original bytes, and network access to `mcp.katalyz.co`. On Team or Enterprise plans, an organization owner may need to add that domain under Code execution → Allow network egress. Claude uploads the bytes to Katalyz's short-lived URL; Katalyz registers it as a temporary AI context resource or a durable library resource according to the requested destination. If any of those capabilities are unavailable, upload files in Katalyz and ask Claude to find them by name. AI room and template creation runs in Katalyz's background worker; Claude checks the result in chat for up to two minutes, or delegates status checks in Cowork or Claude Code when background subagents are available. A failed AI template can be retried in the same draft after Claude reports the reason and you confirm the inputs.

Creating a room, editing its content, posting a comment, or sending an invitation changes live Katalyz data. Buyer invitations queue email and reminders immediately after you confirm the room, recipient, and role. For visual checks, Claude can ask Katalyz for a fresh screenshot of a saved dealroom or template content page; the image does not show the surrounding app controls. Full browser login has its own permission, starts unchecked at authorization, and opens a normal Katalyz session with the seller's application permissions. For help, visit [Katalyz support](https://katalyz.crisp.help/).
